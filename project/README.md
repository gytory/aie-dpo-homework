- **Краткое описание:**  

> Проект посвящен построению сервиса по поиску в базе знаний техподдержки ответов по запросам пользователя.
> Используются синтетические данные, используются модели sentence transformers и индексация faiss.  
> Результат – REST API, который по введенному запросу возвращает топ 5 предположительных ответов на запрос.

---

## 2. Структура проекта

Проект организован в следующей структуре:

- `requirements.txt` – зависимости проекта (библиотеки Python, необходимые для запуска).
- `report.md` – отчёт по проекту (постановка задачи, данные, эксперименты, результаты).
- `self-checklist.md` – чеклист самопроверки проекта перед сдачей.
- `notebooks/` – экспериментальные ноутбуки:
  - `dataset_generator.ipynb` – генерация синтетических данных
  - `exp_01_minilm.ipynb` – эксперименты с моделью MiniLM
  - `exp_02_user2.ipynb` – эксперименты с моделью USER2
  - `exp_03_E5.ipynb` – эксперименты с моделью E5
  - `exp_04_overall&indexation.ipynb` – сравнение индексов и reranker
- `src/` – основной код проекта:
  - `service.py` – API сервис (FastAPI)
  - `models/embedding.py` – загрузка и использование эмбеддинг-моделей
  - `models/index.py` – FAISS индекс для поиска
  - `utils/chunker.py` – разбивка текста на чанки
- `data/` – синтетические данные:
  - `documents.csv` – 40 ответов техподдержки
  - `queries.csv` – 150 тестовых запросов с разметкой
- `configs/` – конфигурационные файлы:
  - `config.py` – пути и параметры модели, чанкинга
- `artifacts/` – сохранённые модели и результаты экспериментов

## 5. Данные

Данные являются собственной генерацией. 
Находятся в папке data.

В файле documents.csv демонстрационная база ответов техподдержки с разделением по темам.

В файле queries.csv расположены примерные запросы пользователей, которые использовались в ноутбуках для замерки метрик.

В файле extended_documents.csv расположены "шумные" документы, которые использовались для расширения базы знаний и замерки изменения скорости при разных индексациях.
